New Relic Browser データ確認

テスト実行後、以下のNRQLクエリでNew Relic上のデータ生成を確認できます。

PageView

ページナビゲーション時に生成されるイベント。各ページロードのURL、読み込み時間、ブラウザ情報を記録。

SELECT count(*) FROM PageView
WHERE appName = 'Flask EC App'
SINCE 30 minutes ago
FACET pageUrl
Page Views を確認
BrowserInteraction

ユーザー操作（クリック、ルート変更）時に生成されるイベント。操作のカテゴリ、ターゲット要素、レスポンスタイムを記録。

SELECT count(*) FROM BrowserInteraction
WHERE appName = 'Flask EC App'
SINCE 30 minutes ago
FACET category, browserInteractionName
Session Traces を確認
AjaxRequest

ブラウザからのXHR/Fetchリクエスト時に生成されるイベント。リクエストURL、ステータスコード、レスポンスタイムを記録。

SELECT count(*) FROM AjaxRequest
WHERE appName = 'Flask EC App'
SINCE 30 minutes ago
FACET requestUrl, httpResponseCode
AJAX を確認
JavaScriptError

JavaScript実行エラー時に生成されるイベント。エラーメッセージ、スタックトレース、発生ページを記録。

SELECT count(*) FROM JavaScriptError
WHERE appName = 'Flask EC App'
SINCE 30 minutes ago
FACET errorMessage, pageUrl
